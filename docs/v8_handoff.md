# Joro + Magic Trackpad 笔记本式主板 v8：交接文档

> 用途：交给 Code 窗口继续优化。本文档记录 v8 的设计意图、全部参数、生成管线、已知问题和下一步待办。
> 单位全部为 mm。坐标系：x 向右（宽度），y 向后（y=0 是靠近用户的前缘），z 向上（z=0 是桌面）。

---

## 1. 设计目标（用户需求汇总）

1. 把 **Razer Joro 键盘**和 **Apple Magic Trackpad（USB-C 版）**组合成一个 MacBook 式的整体，布局是键盘在后、触控板在前居中。
2. **上表面完全水平**，与桌面平行。键盘和触控板的顶面也都水平。
3. 键盘外壳完全藏在主板里面，**只露出键帽**。
4. 触控板玻璃比主板表面**下沉 0.3 mm**，手摸上去要像同一个平面。
5. 键盘和触控板都**从主板底面装进去**，正面看不到任何盖子或螺丝。
6. **隐藏走线**：两根充电线都在壳体内部，从侧面的 USB-C 口充电。
7. 主板尽量精简：尺寸小、材料少，同时结构足够结实，装好后能像拿笔记本一样单手拿起来不散架。
8. 用 3D 打印制作，要能放进 256 × 256 mm 的打印床。
9. 不需要屏幕支架或铰链（用户会另想办法）。

## 3. v8 结构概述

```
        ┌──────────────── 上壳（top case）────────────────┐
  z=19.8│ 1.2 面板：键区开口 + 触控板开口                   │
        │ 2.4 外侧壁，平面圆角 R10，上边倒角 1.0 / 下边 0.8  │
        │ 内部：掌托三角点阵筋 + 隔筋 + 螺丝柱               │
  z=1.6 ├──────────────── 底盖（bottom cover）─────────────┤
  z=0   │ 1.6 三角镂空板 + 斜面支撑条，19 × M3 沉头螺丝       │
        └─────────────────────────────────────────────────┘
```

- **总尺寸**：W 303.6 × D 259.3 × H 19.8
  - H = 面板 1.2 + Joro 后端 16.5 + 泡棉 0.5 + 底盖 1.6
- **键盘**：从底面推进去，铝上盖顶在 1.2 面板的下面，键帽从开口露出（露出量 = 键帽高 − 1.2）。键盘倾斜放置，使它的顶面水平：底面在前端 z≈11.1，后端 z≈2.1。
- **触控板**：从底面装入。面板开口就是触控板外轮廓 + 0.3 间隙，玻璃面在 z = H − 0.3。底面前端 z≈14.6，后端 z≈8.6。
- **夹紧方式**：底盖上的斜面支撑条 + 0.5–1 mm EVA 泡棉，把两个设备压在面板和底盖之间。
- **结构强度**：
  - 掌托区域是三角点阵筋（筋厚 1.6，周期 24），从面板一直连到底盖，形成"面板–点阵–底盖"夹层，整体是一个封闭盒体。
  - 键盘前面有一条 3 mm 实心隔筋，键盘后面有一条 1.2 mm 后墙（在插头位置开槽）。
  - 键盘的铝上盖被压紧后也参与受力。
  - 以上是按结构原理设计的，**没有做过受力仿真**。
- **走线**：
  - 触控板插头位于触控板后方 14 mm 宽的空腔里（用 90° 弯头，插头头部 ≤ 9 mm）。线沿这条空腔向左走，到左侧面的 USB-C 母座。
  - 键盘插头位于键盘后方 13 mm 的区域。线向左走，到左侧面的第二个 USB-C 母座。
  - 两个母座开口都在左侧壁：9.6 × 3.9 跑道形，z 方向居中，用环氧胶从内侧粘牢。
- **底盖**：
  - 三角镂空（筋宽 2.4，周期 18）。边缘 6 mm、螺丝孔周围半径 6 mm、支撑条下方 ±3 mm 范围保持实心。
  - 键盘支撑条 5 条，触控板支撑条 3 条，条宽 2，顶面按设备底面斜度做成斜面。
  - 4 个脚垫凹位（Ø10.5 × 0.6）。
- **体积与重量**：上壳约 172 cm³，底盖约 67 cm³，PETG 约 300 g。加上设备（374 + 230 g），成品约 0.9 kg。

### 螺丝柱位置（共 19 个，M3 热熔螺母，孔 Ø4.2 × 深 6）
- 两侧掌托：x ∈ {12, 62, W−62, W−12} × y ∈ {12, 60, 108}，共 12 个
- 隔筋上：(25, ys)、(W/2−70, ys)、(W/2+95, ys)、(W−25, ys)，其中 ys = kb_y0 − 1.5
- 后部：(W/2−60, yr)、(W/2+60, yr)、(W−25, yr)，其中 yr = D − 2.4 − 3.75

## 4. 关键参数（见 `build_v8.py` 顶部）

```python
skin=1.2; wall=2.4; cover_t=1.6; pad=0.5
tp_drop=0.3; tp_clr=0.3; kb_clr=0.4; key_clr=0.5
corner_r=10; e_top=1.0; e_bot=0.8; pc=0.4          # pc = 开口上沿倒角
front_margin=4; gap_mid=14; seam_rib=3; rear_zone=13
rib=1.6; P_top=24      # 上壳点阵：筋厚 / 周期
web=2.4; P_cov=18      # 底盖镂空：筋宽 / 周期
boss_r=3.75; insert_r=2.1; insert_d=6
kf_inset=(6,6,6,6)     # 键区内缩（左、右、前、后），待实测
tp_port_x=116; kb_port_x=40
```

派生位置：tp_x0 = (W−160)/2 − 0.3，tp_y0 = 4，kb_y0 = tp_y0 + 115.5 + 14 = 133.5，kb_end = kb_y0 + 112.8。

## 5. 生成管线（纯 Python，只用 numpy + scikit-image）

这个环境没有 OpenSCAD 和任何 CAD 内核，所以用 **SDF（有符号距离场）→ marching cubes → 共面区域简化**的方法生成网格。

| 脚本 | 作用 |
|---|---|
| `build_v8.py` | 定义两个 SDF 函数：`top_case(X,Y,Z)` 和 `cover(X,Y,Z)`。`python3 build_v8.py top\|cover 0.4` 按 0.4 mm 体素采样，输出 `<part>_verts.npy` / `<part>_faces.npy` |
| `tiles_v8.py` | `python3 tiles_v8.py top\|cover <0-3>`：把零件切成 4 块并调整打印朝向。上壳在 x = W/2、y = ys_seam 处直接对接切开，并翻转 180°，让光滑面朝下；底盖在 x = W/2+45、y = 70 处切开，带 6 mm 半搭接和 0.1 间隙 |
| `decimate.py` | `python3 decimate.py <prefix> <out.stl>`：先合并重合顶点，再把周围面全部共面（法线点积 > 0.99995）的顶点坍缩掉，每轮只处理互不相邻的顶点集合，邻接数上限 40。最后检查边的流形性和体积守恒，输出二进制 STL |
| `make3mf.py` | 把 8 个 tile STL 打包成 `joro_trackpad_deck_v8.3mf`（3MF core 规范，只有一个打印盘，在切片软件里用自动摆放分盘） |

完整流程：
```bash
for p in top cover; do for i in 0 1 2 3; do python3 tiles_v8.py $p $i; python3 decimate.py tile_${p}_$i tile_${p}_$i.stl; done; done
python3 make3mf.py
```
耗时：采样和 marching cubes 每块几秒，简化每块 1–3 分钟（纯 Python）。

**这套管线的局限**：
- 0.4 mm 体素会把尖锐边缘削成约 0.2–0.4 mm 的小倒角。
- 圆柱面、斜面交线附近的三角面比较密。
- 输出是网格，不是 B-rep 实体：Shapr3D 只能把它当参考体，不能编辑。

## 7. 已知问题和风险

1. **键区开口尺寸是估计的**（`kf_inset`）。如果键区实际更大，键帽会被面板卡住；如果更小，会露出铝上盖。
2. **键帽露出量没有确认**。面板厚 1.2 mm 时，键帽必须至少高出铝上盖 2.8 mm，按到底才不会和面板平齐甚至被卡。如果不够，需要把键盘区域的面板局部减薄到 0.6–0.8 mm，或者让铝上盖从开口中露出来。
3. **上壳后面两块基本只是键盘周围的细边框**（面板 1.2 + 侧壁），单独拿着比较软。整体强度依靠胶接、底盖错缝搭接和压紧的键盘。
4. **上壳接缝是平面对接加胶**，没有定位销或燕尾结构。x = W/2 这条接缝在触控板开口和键区开口处只有面板和窄边框，粘接面积小。
5. **触控板电源开关被封在壳内**，碰不到（触控板会自动休眠，一般不影响使用）。
6. **USB-C 母座只是靠环氧胶粘在侧壁上**，没有螺丝固定，长期插拔可能松动。
7. **触控板 Force Touch 的支撑方式没有验证**。目前是 3 条支撑条加泡棉托住，需要确认触控板底部脚垫的位置，以及按压和触觉反馈是否正常。
8. **3MF 只有一个打印盘**，没有 Bambu/Orca 的多盘信息和切片参数，需要用户在切片软件里自动摆放。
9. 0.4 mm 体素精度下，1.2 mm 的面板只有 3 个体素厚，小倒角和 Ø2.4 以下的小孔精度有限。

## 8. 建议的下一步优化

**A. 换成真正的 CAD 内核（最优先）**
- 用 CadQuery、build123d 或 OpenSCAD 重写，可以直接输出 STEP。这样 Shapr3D 能编辑，边缘也是锐利的，文件更小。
- 按本文档的参数重建：平面圆角外壳 + 抽壳 + 点阵筋 + 螺丝柱 + 开口 + 底盖支撑条。

**B. 接缝强度**
- 上壳接缝加燕尾榫或企口结构，加 Ø1.75 耗材销钉做定位孔。
- 或者重新安排切缝位置，让接缝落在实心筋上。
- 也可以考虑分成 3 块（例如键盘区整条一块），减少穿过开口的接缝。

**C. 键盘区面板**
- 等键帽高度量出来后，决定面板是否局部减薄。
- 键区开口的四个角要和 Joro 键帽外沿的圆角对应。

**D. 母座固定**
- 加一个卡槽或压板结构，用 M2 螺丝固定面板安装式母座，替代纯胶粘。

**E. 轻量化**
- 上壳后部空腔加局部点阵筋，但要避开走线路径。
- 底盖镂空可以改成六边形，或者按受力调整疏密。
- 用 FEA 粗略评估单手拿起一个角时的变形（总重约 0.9 kg）。

**F. 切片交付**
- 如果目标环境装了 OrcaSlicer 或 PrusaSlicer CLI，可以用命令行切片，按用户的打印机直接输出 G-code / .gcode.3mf。
- 需要用户提供打印机型号和喷嘴直径。

**G. 实测后回填参数**
- `kf_inset`、键帽高度、`kb_front_h`（或 `kb_angle`）、`tp_port_x`、`kb_port_x`、触控板实际圆角。
- 建议先打一个试配件：上壳左前块，或只做开口轮廓的 2 mm 薄框。
